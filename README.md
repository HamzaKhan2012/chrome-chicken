# 🐔 Chrome Chicken

A fun, interactive arcade-style web game built from scratch using foundational frontend web technologies. Dodge obstacles, aim for high scores, and test your reflexes!

## 🎮 How to Play

You don't need to install or configure anything to play this game! Follow these simple steps:

1. **Clone or Download the Repository:**
   ```bash
   git clone https://github.com
   ```
2. **Launch the Game:**
   * Open the project folder on your computer.
   * Double-click the `chrome-dino-game.html` file.
   * The game will instantly open and run directly inside your favorite web browser (Chrome, Edge, Safari, etc.)!

---

## 🛠️ Built With
*   **HTML5:** Structured the game canvas, layout, and UI elements.
*   **CSS3:** Styled the game graphics, animations, and responsive boundaries.
*   **JavaScript:** Powering the game mechanics, collision detection, movement logic, and score tracking.
